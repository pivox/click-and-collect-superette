## Note d'hygiène documentaire

Les anciennes docs hors-projet ont été retirées de ce dépôt : elles décrivaient une console d'exploitation sans rapport avec Kadhia, les supérettes, les marchands, les clients, les rendez-vous ou le retrait.

Pour tout nouveau document frontend, conserver le vocabulaire métier Kadhia et le périmètre MVP strict : pas de paiement en ligne, pas de livraison, pas de fidélité, pas de panier multi-marchand.
