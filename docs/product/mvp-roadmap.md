## Pourquoi ce fichier reste un index

Ce fichier contenait une ancienne roadmap courte qui ne reflétait plus fidèlement l'état réel du produit ni les sprints déjà implémentés.

Pour éviter les contradictions entre plusieurs roadmaps, les prochains agents IA et contributeurs doivent utiliser :

1. `docs/Sprint14/README.md` pour la roadmap active à partir de Sprint 14 ;
2. `docs/roadmap/launch-readiness-reorganization.md` pour la synthèse stratégique ;
3. `docs/product/mvp-functional-audit.md` pour l'état Documenté / Codé / Testé / Manquant ;
4. `docs/architecture/api-contract.md` pour les endpoints de référence.

## Règle de contribution

Ne pas recréer une roadmap parallèle dans ce fichier.

Toute évolution de roadmap post-Sprint 14 doit être faite dans `docs/Sprint14/README.md`, puis reportée si nécessaire dans la synthèse stratégique et l'audit fonctionnel.
